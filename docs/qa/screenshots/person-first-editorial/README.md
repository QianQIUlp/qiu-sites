# Person-First Editorial Workbench Visual Evidence

These screenshots support visual review of the `codex/person-first-editorial-redesign` Draft PR and are not part of the site build.

- Each image shows a 1440 × 900 desktop viewport on the left and a 375 × 812 mobile viewport on the right.
- Home, article index, article reading page and projects page each cover both Light and Dark themes.
- Screenshots come from a local `npm run preview` with the browser set to `prefers-reduced-motion: reduce`, so layouts can be compared stably without waiting for entrance animation.
- Screenshots keep only the first viewport; full pages, the 768px layout, no JavaScript, reduced motion, keyboard focus and horizontal overflow are accepted separately per `docs/qa/visual-checklist.md`.
